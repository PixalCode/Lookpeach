# เว็บวันเกิด

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย (ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์)

## โครงสร้างไฟล์
- `index.html`  โครงหน้าเว็บ
- `style.css`   สไตล์ทั้งหมด
- `script.js`   การทำงานของเว็บ (เค้ก, ขอพร, ซอง, พลุ, เพลง)
- `config.js`   **ไฟล์ที่ต้องแก้บ่อยที่สุด** ข้อความในกล่อง และ webhook

## เปลี่ยนข้อความในกล่อง
แก้รายการ `cards` ใน `config.js` (ใบแรกอยู่ตรงกลาง ใบอื่นเรียงล้อมรอบ แนะนำ 7 ใบ)
แต่ละใบมี `title` (หัวข้อบนกล่อง) และ `text` (ข้อความเต็มตอนแตะอ่าน)

## ส่งคำขอพรเข้า Discord
ใส่ URL ของ webhook ที่ `webhookUrl` ใน `config.js` (ใส่แล้ว URL จะมองเห็นได้จากหน้าเว็บ
ถ้าเป็นลิงก์สาธารณะ แนะนำใช้ตัวกลางเช่น Cloudflare Worker แทน)
