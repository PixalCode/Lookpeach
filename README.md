# เว็บวันเกิด

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย (ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์)

## โครงสร้างไฟล์
- `index.html`  โครงหน้าเว็บ
- `style.css`   สไตล์ทั้งหมด
- `script.js`   การทำงานของเว็บ (เค้ก, ขอพร, ซอง, โพลารอยด์, เพลง)
- `config.js`   **ไฟล์ที่ต้องแก้บ่อยที่สุด** รูป ข้อความ และ webhook
- `images/`     รูปทั้งหมด

## เพิ่มโพลารอยด์
1. ใส่รูปในโฟลเดอร์ `images/` (แนะนำ .jpg กว้างไม่เกิน ~1000px ให้ไฟล์ไม่ใหญ่)
2. เปิด `config.js` เพิ่มบรรทัดในรายการ `polaroids`:
   `{ src:'images/ชื่อรูป.jpg', back:'images/รูปหลังการ์ด.jpg', caption:'ข้อความใต้รูป' },`
   (`back` ไม่ใส่ก็ได้ ถ้าไม่ใส่ จะไม่มีรูปให้พลิก)

## เปลี่ยนรูปหรือข้อความการ์ดในซอง
แก้รายการ `cards` ใน `config.js` (ใบแรกอยู่ตรงกลาง ใบอื่นเรียงล้อมรอบ)

## ใส่เพลงของตัวเอง
1. วางไฟล์เพลง เช่น `birthday.mp3` ไว้โฟลเดอร์เดียวกับ `index.html`
2. เปิด `config.js` แล้วแก้ `musicUrl: ''` เป็น `musicUrl: 'birthday.mp3'`
3. อัปโหลดไฟล์เพลงไปพร้อมกับเว็บ เพลงจะเริ่มเล่นหลังจากแตะหรือกดปุ่มครั้งแรก (ตามข้อจำกัดของเบราว์เซอร์)

รองรับไฟล์เสียงที่เล่นได้ในเบราว์เซอร์ เช่น MP3; ถ้า `musicUrl` ว่าง จะใช้เพลงบรรเลงเดิม

## ส่งคำขอพรเข้า Discord
ใส่ URL ของ webhook ที่ `webhookUrl` ใน `config.js` (ใส่แล้ว URL จะมองเห็นได้จากหน้าเว็บ
ถ้าเป็นลิงก์สาธารณะ แนะนำใช้ตัวกลางเช่น Cloudflare Worker แทน)
