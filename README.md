# เว็บวันเกิด

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย (ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์)

## โครงสร้างไฟล์
- `index.html`  โครงหน้าเว็บ
- `style.css`   สไตล์ทั้งหมด
- `script.js`   การทำงานของเว็บ (เค้ก, ซอง, พลุ, เพลง)
- `config.js`   **ไฟล์ที่ต้องแก้บ่อยที่สุด** ข้อความในการ์ดและเพลง

## เปลี่ยนข้อความในกล่อง
แก้รายการ `cards` ใน `config.js` (ใบแรกอยู่ตรงกลาง ใบอื่นเรียงล้อมรอบ แนะนำ 7 ใบ)
แต่ละใบมี `title` (หัวข้อบนกล่อง) และ `text` (ข้อความเต็มตอนแตะอ่าน)
กำหนดสีหัวใจของแต่ละใบด้วย `heartColor` เป็นรหัส HEX เช่น `heartColor: '#e85d75'`

## ตั้งรหัสเปิดซองและคำใบ้
แก้ `envelopeCode` และ `envelopeHint` ใน `config.js` ได้เอง รหัสต้องเป็นตัวเลข 4 หลัก เช่น:
`envelopeCode: '1234'`
`envelopeHint: 'ตัวเลข 1 ถึง 4 เรียงจากน้อยไปมาก'`

## ใส่เพลงของตัวเอง
นำไฟล์เพลง เช่น `birthday.mp3` ไปวางไว้โฟลเดอร์เดียวกับ `index.html` แล้วใส่ชื่อไฟล์ใน `musicUrl` ที่ `config.js`:
`musicUrl: 'birthday.mp3'`
เพลงจะเล่นวนหลังแตะหรือคลิกหน้าเว็บครั้งแรก และปิด/เปิดได้จากปุ่มมุมขวาบน หากเว้น `musicUrl` ว่างไว้ เว็บจะใช้เพลงบรรเลงเดิม
